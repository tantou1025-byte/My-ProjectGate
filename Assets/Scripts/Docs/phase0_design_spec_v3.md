## 1. ゲージ仕様(design_doc.md セクション3を忠実に反映)

### 集中力(Focus)
- 初期値: **100**(10夜目以降は疲労蓄積で初期値**90**に低下)
- 消費量: 軽い観察 **-5** ／ 通常の質問 **-8** ／ 深い尋問・ツール使用 **-15**
- 0になると「思考停止」: その来訪者への追加行動不可、手がかり不足のまま判定を迫られる
- 夜が変わるとリセット(全回復。ただし上記の初期値低下を反映)
- ※v2で入れていた「時間経過によるpassive drain」はdesign_doc.mdに記載がないため**削除**しました

### 施設信用度(Trust)
- 初期値: **100**
- 誤判定(人間を拒否): **-15**
- 誤判定(偽物を通す): **-25**
- 正しい判定: **+3**
- 0でゲームオーバー(施設閉鎖エンド)

### 疑念ゲージ(Doubt)
- 来訪者ごとに0からスタート
- 手がかり発見: **+15〜30**(使用ツールの精度により変動)
- **70%到達で「核心に迫った」演出**が発生し、専用の追加選択肢が出現

## 2. 判定ツール(`Data/judge_tools.csv` 参照)

夜数トリガーで支給。レベル制ではない。12夜目の「全道具精度向上」は
**個別ツールのLvアップではなく、既存ツール全体への一括ボーナス**(ストーリー進行による
一括強化イベント)として扱う。

| 夜数 | 道具 | 効果 |
|---|---|---|
| 1夜目 | (なし) | 目視・会話のみ |
| 2夜目 | 🔦ライト | 瞳の反応を確認 |
| 4夜目 | 🪪ID照会端末 | 入館記録・身分証の整合性確認 |
| 6夜目 | 🩺聴診器 | 心音の有無・異常リズム確認 |
| 9夜目 | 📋チェックリスト | 過去の来訪パターン参照(名無し対策) |
| 12夜目 | (全道具精度向上・グローバル) | 検知範囲・精度が上がる |

FocusCost/DetectionRate/MatchRateBonusの具体数値はdesign_doc.mdに数値記載がないため
CSV内に「仮値」として入れています。テストプレイで調整してください。

## 3. 「再来する個体(名無し)」4段階構成(`Data/recurring_visitor_stages.csv` 参照)

| 段階 | 夜 | 振る舞い |
|---|---|---|
| 1(初登場) | 4夜目 | わかりやすい瞳の異常。拒否すれば一旦姿を消す |
| 2(再訪1) | 7夜目 | 前回拒否を匂わせる。声のトーンのみが手がかりに |
| 3(再訪2) | 10夜目 | 人間に近い振る舞い。複合判定でしか見抜けない |
| 4(最終局面) | 13〜14夜目 | プレイヤーの判定傾向を逆用してくる適応型 |

最終局面の攻略成功が**True Endと専用Hシーン**両方の鍵。

## 4. エンディング10パターン(`Data/endings.csv` 参照)

### 基本4種(Trust + 最終局面での名無し判定で決定)
| エンド | 条件 |
|---|---|
| True End | Trust≥80 ＋ 最終局面で正しい判定 ＋ 正体を完全解明 |
| Good End | Trust≥50 ＋ 最終局面で正しい判定(完全解明でなくても可) |
| Bad End A(施設閉鎖) | Trustが0に到達した時点で即時 |
| Bad End B(見逃し) | Trustは保てたが最終局面で名無しを見逃した |

### 個別キャラ6種(キャラごとの攻略ルートフラグで決定、新規CG不要)
双子の片割れ／元職員の老婆／逃亡者の女／産婆を探す妊婦／蘇りの母／名無し・専用End

⚠️ 「Trust 1〜49 かつ 最終局面で正しい判定」のケースは design_doc.md に明記がない
グレーゾーンです。実装では一旦Bad End B側にフォールバックしていますが、要決定。

## 5. 来訪者28種(`Data/visitor_patterns.csv` 参照)

主要14種(No.1〜14、うち7エントリがキャラ6体のCG/Hシーン持ち。名無しは初登場No.4と
最終形態No.14の2エントリに分かれるため「6体=7エントリ」になります)＋
判定パズル拡張14種(No.15〜28、CGなし、DebutNight=0=任意の夜に差し込み可能)。

GroundTruthHintが`Depends`の来訪者(グレーゾーン)は、シナリオ側で個別に
「このプレイスルーでは人間/偽物のどちらにするか」を決める必要があります
(双子のどちらを通すか、等)。

## 6. Unity実装への取り込み方

1. 上記4つのCSV(`Data/*.csv`)をUnityプロジェクトの`Assets/Data/Source/`に配置
2. `UnityScripts/Editor/ProjectGateDataImporter.cs`をAssets/Editor/に配置
3. Unity Editorのメニュー「ProjectGate > データ一括インポート」を実行
   → VisitorData 28個、JudgeToolData 6個、EndingData 10個が自動生成される
4. 生成されたアセットの台詞・選択肢・スプライト等は手動で詰めていく(これは創作部分)
