## 1. CG生成パイプライン概要

### 1.1 使用ツール・構成

| ツール | 用途 | バージョン |
|---|---|---|
| NovelAI | テキスト→画像生成・i2i介入 | v3 (i2i対応) |
| 手動編集 | 色調補正・部分修正・アセット合成 | Photoshop等 |

### 1.2 生成フロー

```
元絵/コンセプト
  ↓
NovelAI プロンプト作成（日本語）
  ↓
生成実行（複数サンプル）
  ↓
表情・構図の評価（ユーザーレビュー）
  ↓
[必要に応じて]
  i2i介入 (多腕化・緑青亀裂追加等)
  ↓
最終品質チェック（66%基準）
  ↓
アセット化・docs/cgKey_mapping_candidates.csv に登録
```

## 2. NovelAI プロンプト戦略

### 2.1 基本構成

**日本語プロンプト フォーマット:**
```
[キャラクター描写], [服装・装飾], [シーン設定], [表情・動作], [光・色調], [画風指定]
```

例）
```
月物の女、淡紫の着物、夜間の古い館の廊下、不安げな表情、柔らかい月明かり、ちび水彩風
```

### 2.2 キャラクター別パラメータ

#### BondEvent_001: 主人公・提灯少女
- **基本コンセプト**: ちび水彩スタイル、元気で可愛い
- **固定要素**: 
  - 淡い色使い（緑青系の髪、焦げ茶の瞳）
  - 小柄で幼い体格
- **表情バリエーション** (5パターン確定):
  1. 無表情（通常）
  2. 笑顔（親愛）
  3. 困惑
  4. 驚き
  5. 怒り
- **衣装**: 固定（着物のみ）
- **シーン**: s1=玄関, s2=夜道, s3=室内
- **品質評価**: 5/5 ✓合格

#### BondEvent_010: 骹熊
- **基本コンセプト**: 墨絵調・重厚感・ボス専用スタイル
- **固定要素**: 
  - 濃紺・黒基調
  - 大柄でいかつい体格
  - 異形要素（アニマル的特徴）
- **表情バリエーション**: 
  1. 無表情（通常・獰猛）
  2. 薄笑い
  3. 怒り
  4. 警戒
  5. 落胆
- **衣装**: 異形用スーツ（固定）
- **シーン**: s1=暗い玄関, s2=影の部屋, s3=対峙シーン
- **品質評価**: 5/5 ✓合格（墨絵調の確立に成功）

#### BondEvent_101: 骨塔
- **基本コンセプト**: v5確定（v8/v9は全面崩壊のため廃棄）
- **v5の方針**: 
  - 骨骼感（スケルトン）と人間らしさの融合
  - モノトーン基調に微妙な色差
  - 儀礼的・宗教的雰囲気
- **v8/v9失敗要因**: 
  - プロンプトの完全再構成（コンセプト喪失）
  - 生成品質が大幅低下
- **現在の全面再プロンプトは不推奨**
- **品質評価**: 5/5 ✓確定（v5で完成）

#### BondEvent_111: 灰堕の欠片
- **基本コンセプト**: 緑青色基調・腐蝕・崩壊イメージ
- **配色バイアス**: 
  - NovelAIの生成エンジンが「灰色・グレースケール」を過度に優先
  - 「緑青色」指定しても灰色になる技術的限界を確認
  - ユーザー承認済みで保留
- **代替案検討**: 
  - RGB値の直指定（プロンプトに数値埋め込み）は未テスト
  - i2i + 色調補正による事後修正（工数大）
- **品質評価**: 4/5 🟡保留（仕様確定待ち）

#### BondEvent_151: ???
- **テスト状況**: 耳のみ描画バグ（個別要因）
- **原因**: 
  - キャラクターの複雑な角度指定で、部分描画の崩れ
  - i2i再描画で一度は改善するも、再発の可能性
- **現在の対応**: 
  - v5で一旦保留
  - 部分描画のプロンプト微調整を要検討
- **品質評価**: 3/5 🟡保留

#### BondEvent_002: ???
- **テスト状況**: キャラ形状が不成立（基本形状が崩壊）
- **原因**: 
  - プロンプトの複雑さが高すぎる可能性
  - 体型・頭部・四肢の比率指定の競合
- **現在の対応**: 
  - シンプルプロンプトから再スタート推奨
  - 段階的に要素追加する反復手法
- **品質評価**: 3/5 🟡保留（形状確立まで待ち）

### 2.3 i2i（Img to Img）介入テクニック

**適用状況: Phase 0テスト中**

#### 実施内容
- **多腕化**: キャラの腕の数・角度を補正
- **緑青亀裂追加**: 腐蝕表現を部分的に上乗せ
- **色調微調整**: RGB値の局所的な補正

#### パラメータ テンプレート
```
Strength: 0.5〜0.7 (0.5=軽い介入, 0.7=強い介入)
Schedule: Uniform
Seed: 固定 or ランダム
ノイズ: 中程度(0.3〜0.5)
```

#### 適用例（BondEvent_111の改善試行）
```
元画像: 灰色系のBondEvent_111
強度: 0.6
追加ノイズ: 緑青カラーレイヤー
結果: 色が緑青に寄ったが、まだ完全でない
→ さらなる調整必要
```

## 3. 品質評価基準（66% 達成基準）

### 3.1 合格条件（5/5）

- ✓ キャラクター識別性が確保されている
- ✓ 表情・動作が意図通り（5パターン全て）
- ✓ 色調・光が設計意図に合致
- ✓ 異常な崩れ・欠損なし
- ✓ 全シーンバリエーション（s1, s2, s3）が統一感を持つ

### 3.2 保留条件（3〜4/5）

- ⚠️ 個別部分に微細なバグ（耳、手等）
- ⚠️ 配色バイアス（技術限界と判断）
- ⚠️ 完全再生成でコンセプト崩壊のリスク
- → **ユーザー判断待ち**で進行を中断しない方針

### 3.3 不合格条件（〜2/5）

- ✗ キャラクター形状が基本的に成立していない
- ✗ コンセプトと異なる見た目
- ✗ 複数パターンの大きな矛盾
- → **再生成必要**

## 5. 今後の検討事項

### 5.1 未決定の仕様

#### RGB値直指定による配色制御
```
プロンプト例:
"RGB(0,200,100)系の緑青色, ..."
```
- **効果**: 配色バイアス回避の可能性
- **検証**: 未実施（i2i + 色補正の工数 vs 効果）

#### シンプルプロンプト vs 詳細プロンプト
- **シンプル**: BondEvent_001の成功事例
- **詳細**: バリエーション多く指定すると崩壊（BondEvent_002）
- → **キャラごとに最適レベルを探索する必要あり**

### 5.2 今後のテストロードマップ

1. **段階1**: BondEvent_151, 002 の形状確立
2. **段階2**: 配色バイアス対策（RGB直指定か色補正か検証）
3. **段階3**: Hシーン群の生成テスト（個別ガイドライン検討）
4. **段階4**: イベントCG・背景の統一スタイル確立
